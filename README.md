# dawa4u

Medicines from a licensed local pharmacy, delivered by a local rider in 10–15 minutes.

| Folder | What it is |
|---|---|
| [`dawa4u-supabase/`](dawa4u-supabase/README.md) | **Full version** — Supabase backend (database, phone OTP, Razorpay, live updates) with five apps: customer website, customer phone app, pharmacy dashboard, rider app (English/Hindi) and admin; plus native Android/iPhone packaging. Start here. |
| [`dawa4u-app/`](dawa4u-app/README.md) | First version — single Node.js server with a JSON-file database. Kept for reference. |
